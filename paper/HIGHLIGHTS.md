# Highlights

Elsevier requires three to five bullets, each **no more than 85 characters including
spaces**, free of jargon, acronyms and abbreviations. Submitted as a separate file at
Environmental Modelling & Software and Atmospheric Pollution Research. Not used by arXiv.

Character counts are verified by `scripts/check_highlights.py`, which fails if any bullet
exceeds the limit — the constraint is easy to break during editing and the submission
system rejects the file rather than truncating it.
